`to-plan`, `writing-great-plan` and `whatnext`: plans written outside a workspace now default to `.scratch/plans/`, next to the default workspace root `.scratch/workspaces/`, instead of `.plans/`. All your local notes now sit under `.scratch/` by default. When your workspace root is a `workspaces/` folder somewhere else (such as `_local/workspaces/`), the plan root offered is its sibling (`_local/plans/`). A repo that already has a `Plan root:` line keeps it.
