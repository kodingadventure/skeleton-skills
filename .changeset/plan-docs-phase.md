`writing-great-plan`: a feature plan that changes behaviour now ends with a docs phase, reviewed and committed like the code. It holds one item per installed documentation skill (`update-wiki` for the wiki, `refine-docs` for glossaries and reference docs); a repo without a wiki gets one only when there is something to write. Missing tests become their own phase before it. A doc sentence that one code phase makes wrong is fixed in that phase.
